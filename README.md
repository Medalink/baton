# baton

baton records every coding-agent turn as a git commit and syncs it live between your machines through a server you host. Pick up any agent's work on another machine without committing, see which agent message wrote which line, and rewind a thread to any turn.

It is early and not usable yet. The design is in [docs/design.md](docs/design.md).
